# Ecommerce-Purchases-Data-Analysis
Data analysis of the Ecommerce Purchases dataset using Python and Pandas. Solving 15 real-world data analysis questions through data exploration, filtering, aggregation, and insights.

Ecommerce Purchases Data Analysis Using Python

Project Overview

This project focuses on analyzing an Ecommerce Purchases dataset obtained from Kaggle using Python and Pandas. The objective is to explore customer purchase information, identify patterns, and extract meaningful insights by solving 15 data analysis questions.

Dataset

- Dataset Name: Ecommerce Purchases
- Source: Kaggle
- Format: CSV

Technologies Used

- Python
- Pandas
- Jupyter Notebook

Analysis Questions

1. Display the top 10 rows of the dataset.
2. Display the last 10 rows of the dataset.
3. Check the data type of each column.
4. Identify null values in the dataset.
5. Find the total number of rows and columns.
6. Find the highest and lowest purchase prices.
7. Calculate the average purchase price.
8. Count customers whose language is French (fr).
9. Find job titles containing the word Engineer.
10. Find the email address associated with a given IP address.
11. Count Mastercard users who made purchases above 50.
12. Find the email address associated with a given credit card number.
13. Count purchases made during AM and PM.
14. Count credit cards expiring in 2020.
15. Identify the top 5 most popular email providers.

Key Concepts Covered

- Data Loading
- Data Exploration
- Data Cleaning and Null Value Checking
- Descriptive Statistics
- Data Filtering
- String Operations
- Conditional Selection
- Data Aggregation
- Value Counts

Project Objective

To develop practical data analysis skills using Pandas and understand how to extract useful information from real-world ecommerce customer data.
